# Goal Tracker - Product Requirements Document

## 1. Overview


### 1.1 Product Description

A simple, personal tracking app that allows me to track various metrics associated with my goals, and easily review the data for insights

### 1.2 Product Vision

An app that helps me keep on track of my fitness, learning and personal development goals by enabling seemless in-the-moment tracking of key metrics, and simple retrieval and analysis of the data.

## 2. Goals and Objectives

### 2.1 Primary Goals

- Help me stay engaged with my goals

## 3. Target Audience

- Myeself: 41 year old Dad, senior technology professional and partner, who wants to:
- - be a lifelong learner
- - stay active and healthy
- - be a good parent and partner
- - relax and enjoy life

## 4. Core Features

### 4.1 Basic Mechanics
Set up metrics

- Set up a number of metrics to track in-the-moment throughout my day
- Log a value against a metric
- View a dashboard of a single metric by week / month / year / all-time
- View a dashboard of all metrics by week / month / year / all-time
- Send an overview of week to Tana

## 5. User Stories

### 5.1 Core User Stories
1. **As a user**, I want to add a new metric to track

Metrics can be:
- time based: e.g. time spent exercising / meditating / reading
- cumulative e.g. log an occurance of eating a sugary snack
- reflections e.g. log a reflection about an interaction I had

2. **As a user**, I want to track a metric
- time based: start and end timer for the metric
- cumulative: log occurance
- relfection: open journal and type entry


3. **As a user**, I want to review a metric
- time based: how much time spent this week / month / year, diff on previous period
- cumulative: how many this week / month / year, diff on previous period
- relfection: all entries this week / month / year, diff on previous period
